# numj-natives-windows-x86_64

This artifact contains only the native library for numj on Windows x86-64 (no Java code), so its sources and
javadoc jars contain this file only.

* Fortran sources: https://github.com/hareramray/numj/tree/main/native (`numj_kernels.f90`, `numj_reduce.f90`,
  `numj_elementwise.f90`, generated by `gen_elementwise.py`); build: `scripts/build.ps1`.
* API documentation: the javadoc jar of `io.github.hareramray:numj`.
* Licensing of the statically linked GCC runtime: `META-INF/NOTICE` in the main jar.
